# PDF Editor Guide (Batch 11)

## Cara pakai

1. Buka tool PDF Editor.
2. Unggah file PDF (maks 50 MB, harus signature %PDF-).
3. Kelola halaman: pindah atas/bawah, putar 90°, duplikasi, hapus.
4. Tambah catatan teks, kotak, atau gambar/tanda tangan (PNG/JPEG).
5. Undo untuk operasi terakhir.
6. Unduh PDF hasil.

## Batasan

- Bukan pengedit teks asli yang tertanam di PDF.
- Catatan teks dan gambar adalah overlay.
- Tanda tangan adalah gambar, bukan sertifikat digital.
- PDF terenkripsi/password: tidak didukung (pesan error).
- Crop halaman belum diimplementasi di UI.
- Highlight/underline/strikethrough teks-aware belum ada.
- Semua pemrosesan lokal.
